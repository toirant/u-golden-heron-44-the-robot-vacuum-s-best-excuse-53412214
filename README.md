## The entry

## How it works

`main.ts` writes the entry line to `/output/entry.txt` and prints it with its character count. It validates the line locally before writing: exactly one line, 1–140 characters, no runs of whitespace — the same gate the sealed scorer applies.

## Run

```sh

```

No dependencies, no flags, no network.
